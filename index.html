How to think about building it

1

Create a main website

Your homepage introduces you and lists your projects with clear links to each one.

2

Give each project its own section

Each project gets its own folder and page so it can grow without cluttering the homepage.

3

Upgrade showcase pages into real apps

When a project is ready, replace placeholder content with the actual code, interface, and logic for that app.
